## The event

GraceDB superevent S250119cv (2025-01-19 19:02:54 UTC, t0 = 1421348576.32),
CBC, instruments H1 L1 V1, preferred event from MBTA with FAR 4.0e-20 Hz
(one per 8e11 years), also found by gstlal, spiir, pycbc and cWB. The
strain is not public; access used the `fan.zhang@ligo.org` credential.

## What ran

Request: "Fetch strain data for 1421348576.32, check data quality, run
Aframe detection and AMPLFI parameter estimation." with
`--data-source nds2 --ifos H1 L1 V1 --aframe-far 365.25` on the GPU node.

- `data.fetch` (source `nds2`) streamed 128 s of `H1:GDS-CALIB_STRAIN_CLEAN`,
  `L1:GDS-CALIB_STRAIN_CLEAN` and `V1:Hrec_hoft_16384Hz` at 16384 Hz from
  `nds.ligo.caltech.edu` with the node's Kerberos ticket (the `nds2` bindings
  run in the node's conda environment through `ML4GW_NDS2_PYTHON`), then
  resampled to 2048 Hz.
- `data.inspect`: all three detectors present, finite, science mode.
- `aframe.detect` (H1+L1): statistic **8.50**, above the calibrated 1/day
  threshold 2.70; predicted coalescence 1421348576.234, **0.086 s before**
  the superevent t0 and inside the 2 s candidate window.
