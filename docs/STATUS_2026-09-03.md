## How the pieces fit

```
prompt ──► planner (baseline | LLM, validated as PlanSpec, policy) ──► estimate + budget
      ──► runtime (executor: local | htcondor | ssh) ──► adapters (fail closed)
      ──► manifests + report + experiment memory
```

Real adapters: `data.fetch` (GWOSC, LDG), `data.inspect`, `aframe.detect`
(calibrated threshold, candidate window), `amplfi.pe` (HL/HLV),
`buoy.analyze` (records detectors actually used),
`deepclean.check_applicability`, `deepclean.clean`, `analysis.reconcile`;
`gwak.scan` and `deepclean.clean` fail closed with the reason when their
models or witnesses are unavailable.
