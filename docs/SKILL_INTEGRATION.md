# 上游开发者接入清单（契约 1.0）

事实来源是 [12 份 YAML](../src/ml4gw_agent/skill_manifests/)、
[SkillSpec](../src/ml4gw_agent/models.py) 和
[适配器注册表](../src/ml4gw_agent/adapters/__init__.py)。保持现有字段兼容；
`machine_check` 是检查名称声明，并不是可执行插件或自动分派入口。

| 交付项 | 上游提供 | 本仓库负责 / 验收方式 |
|---|---|---|
| 输入 / 输出 | JSON Schema、必填项、默认值和稳定字段；明确失败是否有部分输出 | 注册表验证 schema；运行时在引用解析后验证输入、返回后验证输出 |
| 科学约束 | 采样率 Hz、应变单位、GPS 秒、探测器顺序、时间范围、预处理和训练适用域 | 适配器逐项检查并给出拒绝原因；无法机器判断的适用域列入领域评审 |
| 前置条件 | 所需包、凭据类型、witness、模型与校准文件、缺失时的行为 | `probe()` 检查本机安装，`preflight()` 检查请求，`execute()` 检查实际数据与模型 |
| 安装与发布 | 版本化软件包、支持的 Python / CUDA、锁定依赖、正式容器及摘要 | 可选依赖组、固定入口、CI；注册表不允许任意导入代码 |
| 模型来源 | 不可变 revision / SHA-256、训练者、数据区间及权限、训练配置、导出命令 / 环境 | 核验权重与记录，保留元数据；未知归属标待确认，不能从哈希推断作者 |
| 资源与风险 | CPU / RAM / GPU、典型时延和输入规模、破坏性操作与审批要求 | 合同资源提示、计划估计、预算检查、高风险执行策略；估计并非资源硬配额 |
| 错误与恢复 | 缺包、缺模型、凭据失败、输入不兼容、科学验证失败的可区分原因 | 转为 `AdapterUnavailableError` / `AdapterError`；记录失败，依赖阻断，有限重试 |
| 结果与产物 | HDF5 / JSON / FITS 等格式、字段、单位、有限值及验收容差、参考案例 | schema 与文件检查，记录路径 / 大小 / SHA-256；科学正确性由领域评审确认 |
| 长期维护 | 上游 API 变更、版本发布、正式模型与容器、许可证及分发授权 | 适配接口、契约版本、规划映射、运行记录、CLI / Web / MCP 集成及回归测试 |

接入顺序：提交契约和上述证据 → 在注册表增加固定适配器入口 → 用小型离线
样本验证成功与拒绝路径 → 对同一固定模型运行直接调用和 agent 对照 → 记录
领域审核人和日期。不要仅因软件测试通过就将 `experimental` 改成 `stable`。

完整例子见 [Aframe 契约与调用](SKILL_CONTRACT_EXAMPLE.md)。模型待确认事项见
[来源核对表](MODEL_PROVENANCE_REVIEW.md)。外部 agent 使用
[MCP 完整流程](MCP.md)，科学技能由计划统一编排。
